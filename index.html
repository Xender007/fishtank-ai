about saving

The champion of each generation is stored in this browser automatically, so a refresh does not throw the run away. Save best writes a JSON file: a list of numbers and a list of which node feeds which. That is the whole learned behaviour. Kin senses are built but ship off — measured, they cost fitness and produced no schooling. Flip senses.neighbours in js/config.js to explore them.
